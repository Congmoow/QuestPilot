# Tauri 发布人工验收清单

> 用途：记录 `npm run test:smoke:tauri` 无法替代的真实 Tauri 窗口、系统文件对话框和打包产物点击验收。完成后把日期、运行时、命令或产物路径、验收人和遗留风险补回发布记录。

## 验收前置

- [ ] 已运行 `npm run test:smoke:tauri`，记录结果。
- [ ] 已运行发布前基础命令清单中的必要自动化命令，记录失败项或跳过原因。
- [ ] 已确认本次使用的运行时：`npm run tauri:dev`、release exe 或 NSIS 安装包。
- [ ] 已准备一个有效 CSV 文件、一个非法或不匹配路径样例、一个包含用户数据的旧 Electron 数据库候选。

## 文件选择与保存对话框

- [ ] CSV 文件选择成功：在真实系统文件对话框中选择有效 `.csv`，页面显示文件名。
- [ ] CSV 文件选择取消：打开文件对话框后取消，页面仍停留在上传空态且不出现错误提示。
- [ ] CSV 非法路径或错误文件：选择或输入不符合预期的文件后，页面给出可恢复错误，不导入脏数据。
- [ ] CSV 模板下载取消：打开保存对话框后取消，页面不误报成功。
- [ ] CSV 模板下载成功：保存文件后可打开，表头和示例内容正确。
- [ ] CSV 题库导出取消：取消保存时不生成文件，不误报成功。
- [ ] CSV 题库导出成功：保存文件后可打开，导出数量和内容与题库一致。

## 数据迁移点击流程

- [ ] 目标 Tauri 库缺失：应用启动或设置页迁移状态符合预期，不提示不必要的危险替换。
- [ ] 目标 Tauri 库为空：检测到旧库数据时走自动迁移或推荐迁移路径，结果可重启后读取。
- [ ] 目标 Tauri 库已有用户数据：设置页显示“检测到旧库数据”和候选旧库。
- [ ] 点击“备份并使用旧库替换”后出现危险操作确认弹窗。
- [ ] 取消危险确认后不会调用替换流程，当前数据库保持不变。
- [ ] 确认替换后会先生成当前库备份，再用旧库替换目标库。
- [ ] 重启应用后数据状态与所选旧库一致，备份文件仍可定位。

## 窗口控制

- [ ] 拖拽标题栏可移动窗口，按钮区域不可拖拽误触。
- [ ] 最小化按钮可将窗口最小化，并能从任务栏恢复。
- [ ] 最大化按钮可最大化窗口，按钮状态切换为还原。
- [ ] 还原按钮可恢复窗口尺寸，按钮状态切回最大化。
- [ ] 关闭按钮可关闭应用，重新打开后核心数据仍可读取。
- [ ] 异常退出或强制结束后重新打开，数据库未损坏，页面可恢复。

## 打包产物核心流程

- [ ] NSIS 安装包可完成安装，安装后桌面或开始菜单入口可启动。
- [ ] release exe 可直接启动并停留在主窗口，不出现白屏或崩溃。
- [ ] 题库列表、新建题库和题库详情可正常使用。
- [ ] 手动录题可保存题目，重启后仍可读取。
- [ ] CSV 导入可完成解析和导入。
- [ ] 错题本可查看、练习和清理。
- [ ] 设置页 API 配置保存后不回显完整 Key。
